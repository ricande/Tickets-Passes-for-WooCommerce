# Security policy

## Supported versions

| Version | Supported |
|---|---|
| 1.3.x (RC / current development) | Yes |
| 1.2.3 and earlier | No security patches from this repository |

1.3.0 RC is a pre-release. Treat findings against this branch as current development.

## Reporting a vulnerability

**Do not open a public GitHub issue** for a security vulnerability.

Use [GitHub Private Vulnerability Reporting](https://github.com/ricande/Tickets-Passes-for-WooCommerce/security/advisories/new) if it is enabled on this repository.

If that form is not available, contact a repository maintainer **privately** through GitHub (do not post exploit details, file paths to secrets, or customer data in a public issue or discussion).

Please include:

- Plugin version
- WordPress, WooCommerce and PHP versions
- Steps to reproduce
- Impact (what an attacker can do)

Do not attach credentials, dumps, or live customer codes.
